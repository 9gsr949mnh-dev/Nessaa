# Birthday Website

This is a static multi-page birthday website that works on GitHub Pages.

## Edit the personal details

Open `content.js` and change:

- `girlfriendName`
- `yourName`
- homepage text
- letter text
- memories
- the `reasons` list

If you want photos in memories, put your photos in an `images` folder and set a memory image like:

```js
image: "images/memory-1.jpg",
```

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder.
3. In GitHub, go to `Settings > Pages`.
4. Set the source to `Deploy from a branch`.
5. Choose the `main` branch and `/root` folder.
6. Save, then wait for GitHub to give you the live link.
